# Run Report Template

Use this exact section structure.

```markdown
# Run Report

## Executed as planned
- ...

## Deviations from plan
- ...

## Failed runs
- config, seed, traceback summary, action taken

## Compute consumed
- planned: X GPU-hours
- actual: Y GPU-hours

## Headline number
- one sentence the paper should lead with

## Reproducibility manifest
- git commit
- hardware
- seeds
- config files
```
